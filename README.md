# Registration Form

About

A simple and user-friendly registration form built using HTML and CSS.

Features

- User registration form with input fields
- Required field validation
- Email format validation using HTML
- CSS styling for a clean interface
- Image assets used in the project

Technologies Used

- HTML5
- CSS3

How to Run

1. Download or clone this repository.
2. Keep the HTML, CSS, and image files in their original folder structure.
3. Open the HTML file in any web browser.

Purpose

This project was created to practice HTML forms, input validation, and CSS styling.
